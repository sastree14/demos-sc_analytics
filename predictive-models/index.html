REFERENCE NOTESMETHODOLOGY & LIMITATIONS

Behind the numbers

What the working example calculates, what it does not claim, and what an actual engagement would include.

01 / SOURCE DATA

Reproducible examples

Historical demand and shipment outcomes are mathematically generated. Real engagements start with data discovery, source-quality checks, target definitions and leakage controls.

02 / FORECASTING

Three actual methods

The seasonal baseline repeats the same month from the previous year. Seasonal + trend fits a linear trend and monthly residual effects. The weighted ensemble combines both with fixed weights.

03 / VALIDATION

Evidence before projection

The final eight historical months are held out. WAPE, MAE and signed bias are computed against the actual synthetic observations. Accuracy is displayed as 100 − WAPE and should not be interpreted as a universal success rate.

04 / RISK CLASSIFICATION

Fitted logistic regression

The risk example fits model coefficients with gradient descent on synthetic training cases. Held-out precision, recall and F1 are calculated using a 50% classification threshold.

05 / UNCERTAINTY

Indicative, not guaranteed

The future chart uses historical absolute holdout errors to create an illustrative range. It is not a calibrated probabilistic prediction interval, and no reliability promise is implied.

06 / MODEL SELECTION

Appropriate to the problem

Other client problems may call for tree ensembles, neural networks, classification, anomaly detection or reinforcement learning for sequential decisions. Those methods are not falsely presented as running in this example.
